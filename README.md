# System Administrator Career Portfolio: Fundamentals

A responsive student portfolio built with **HTML5, CSS3, and vanilla JavaScript**. It has no database, login system, or build tools.

## Files
- `index.html` — website content and sections
- `style.css` — responsive layout, colors, cards, and animations
- `script.js` — mobile navigation, active navigation state, and footer year
- `screenshots/` — place your final desktop and mobile browser screenshots here

## Run locally
1. Extract the ZIP file.
2. Open `index.html` in a web browser.
3. For local server preview, open a terminal in this folder and run:
   - Python: `python -m http.server 8000`
   - Then visit `http://localhost:8000`

## Personalize before submitting
- Confirm the developer name, course, and school in the About section.
- Update `mailto:` in the “Let's Connect” link if you want it to open your email.
- Take screenshots of the Home section and at least one lower section on desktop and mobile.
- Upload the folder to your instructor-approved hosting service if a public URL is required.

## Features
- Working anchor navigation and responsive mobile menu
- Responsibilities, technical/professional skills, and six system administration tools
- External official documentation links open in a new tab
- Responsive design for desktop, tablet, and mobile
- Accessible menu labels and reduced-motion support
